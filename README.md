# ML_itmo
Задача - предсказание оттока клиентов банка.

Бизнес-постановка задачи: Банку важно заранее понимать, какие клиенты с высокой вероятностью перестанут пользоваться услугами банка. Это позволяет вовремя запускать удерживающие меры, чтобы повысить retention.

ML-постановка задачи: Задача бинарной классификации: 1 - клиент уйдет из банка 0 - клиент останется

Набор данных: Датасет из ABC Multistate bank, потому что он содержит целевую переменную - факт ухода клиента (churn), включает числовые и категориальные признаки, позволяет провести содержательный EDA.

branch HW1 - EDA анализ
branch HW2 - Расчет Recall с помощью ML моделей
branch HW3 - Добавление t-test
